# GCIA exploratory pilot manuscript

English research draft; author and affiliation information must be completed.
Import this ZIP into Overleaf, select main.tex, compile with pdfLaTeX (twice).
No bibliography processor is needed. Figures are included as vector PDF and 300-dpi PNG.
The data folder contains the recorded numerical results and SHA256 provenance.
No raw histology images or model weights are redistributed.

This is not a submission-ready clinical validation. BACH and expert review were not performed; no claim of independently validated clinical concept use is supported.
No local LaTeX compiler was available when creating the archive; source checks are not PDF compilation.

Recreate figures/tables/archive from the GCIA repository using scripts/build_pilot_paper.py. The main.tex manuscript is maintained separately.
